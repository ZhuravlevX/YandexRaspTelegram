**Railways Timetable Telegram** – это бот написанный на языке «Python», позволяющий узнать расписание ближайших пригородных поездов, поездов дальнего следования по указанному маршруту пользователя, а также построения пути для «Московского Метрополитена». Поддерживает для поиска расписаний пригородных поездов (Россия и Беларусь) и поездов дальнего следования (Россия, Беларусь, Северная Корея, Казахстан, Китай и Монголия).  

### Откуда берутся данные об расписаниях и построения маршрута

Данный бот получает данные при помощи [API Яндекс.Расписаний](https://yandex.ru/dev/rasp/) и API MosMetro. API организован в соответствии с принципами REST. Взаимодействие с [API Яндекс.Расписаний](https://yandex.ru/dev/rasp/) осуществляется по протоколу HTTPS посредством GET-запросов. Сервис возвращает данные в форматах: JSON, XML. В нашем случае, бот получает данные в JSON формате. Взаимодействие с API MosMetro происходит через Backend.

### Функционал бота  
  
- Вывод актуальных расписаний пригородных поездов и поездов дальнего следования на текущую дату по указанному маршруту следования пользователем.  
- Построения детального маршрута следования с пересадками, загружености электропоезда и прибытием «Московского Метрополитена».  
- Изменение маршрута следования пользователем для расписаний видов транспорта. 
- Автообновление последнего вызванного пользователем расписание или построенного пути в течение часа, обновляя информацию на актуальную, а также в случае необходимости отмены автообновления.
- Отключение автообновление и очистка текущего маршрута следования.
- Случайные изображения пригородных поездов, поездов дальнего следования и электропоездов «Московского Метрополитена» для разнообразия в функциях расписания и не только. 

  
### Установка бота  

 В данном боте используются следующие модули, требуемые к установке:  
 - `Aiogram` – версии 3.17.0  
 - `Requests` – версии 2.32.3  
 - `Babel` – версии 2.16.0  
 - `Pytz` – версии 2024.2  
 - `Python-dotenv` - версии 1.0.1
 - `Pydantic` - версии 2.10.4
 - `Json5` - версии 0.10.0
 - `motor` - версии 3.6.0 и выше
 - `pyowm` - версии 3.3.0 и выше
  
Для установки всех модулей проекта, присутствует файл `requirements.txt`, которым можно воспользоваться при помощи команды в терминале проекта.
```
pip install -r src/requirements.txt
```

Для того чтобы бот функционировал, необходимо создать в папке `src` файл с именем `.env` и впишите туда следующие параметры:

```
TOKEN_YANDEX=Токен_Яндекс_Расписаний  
TOKEN_BOT=Токен_telegram_бота
MONGO_URL=Cсылка_базы_данных
ADMIN_ID=Ваш_айди_telegram
MOSMETRO_API_URL='https://prodapp.mosmetro.ru/api'
ROUTER_API_URL='https://mosmetro.ru/router/api/routes'
```
Без данного файла, бот функционировать **не будет**.

### База данных: MongoDB  

[**MongoDB**](https://www.mongodb.com/) — бесплатная система управления базами данных, которая работает с документоориентированной моделью данных. Для того чтобы бот сохранял информацию и мог функционировать, необходимо получить ссылку для подключения к базе данных.

Перед тем, как получить ссылку для подключения к базе данных, вам нужно создать кластер. После чего нажмите на кнопку **Connect** и затем выберете тип подключения **MongoDB for VS Code**. Далее скопируйте ссылку и вставьте её в файл `.env` в строку `MONGO_URL=`.

### Backend: API MosMetro 

**Backend** — это невидимая часть приложения, которая отвечает за обработку данных и связь с сервером. Он управляет базами данных, логикой работы и API, обеспечивая корректную работу сервиса.

У нашего Backend имееться следующие виды запросов:
- `/station/search?q={название}` – поиск станций из перечисленных доступных по названию.
- `/station/mini/{id}` – получение минимальной полезной информации о станции по айди.
- `/station/{id}` – получение всей информации о станции.
- `/schema` – получение всех станции «Московского Метрополитена».
- `/notifications` – получение всех предупреждений, информации «Московского Метрополитена».
- `/line/{id}` – получение информации о линии по айди.
- `/route?from={ОТКУДА}&to={КУДА}` – информация об построенном маршруте.
- `/wagons/{id}` – получение сведений о поездах прибывающих на станцию по айди _(пока что просто пересылает ответ «Московского Метрополитена» не изменяя его)_

Для того чтобы вызвать запрос, в начале добавьте **http://127.0.0.1:8080/**, после чего выбирете тот запрос, который вам нужен.

### Конфигурация бота  

В боте вы можете поменять значения по своему удобству и желанию. На текущий момент для изменения, доступны следующие параметры:  
- `token_yandex` – токен Яндекса, который нужно получить на сайте [API Яндекс Расписаний](https://yandex.ru/dev/rasp/raspapi#examples), иначе бот работать не будет.  
- `token_bot` – токен бота Telegram на который будут отправляться данные. Сам токен можно получить у [BotFather](https://telegram.me/botfather).  
- `suburban_url` – ссылка изображений электричек, которые будут случайно изображаться вовремя вызова расписания электричек. Формат `.webp` не поддерживается, иначе бот не будет корректно работать.  
- `train_url` – ссылка изображений поездов, которые будут случайно изображаться вовремя вызова расписания поездов дальнего следования. Формат `.webp` не поддерживается, иначе бот не будет корректно работать.
- `underground_url` – ссылка изображений электропоездов, которые будут случайно изображаться вовремя вызова построения пути к конечной станции в «Московского Метрополитене». Формат `.webp` не поддерживается, иначе бот не будет корректно работать.
- `suburban_map` – эмодзи под типы видов электричек. Можно изменять и добавлять новые при необходимости.  
- `train_map` – эмодзи под типы видов поездов. Можно изменять и добавлять новые при необходимости.
- `numbers_trains_maps_emojis` – эмодзи под виды поездов дальнего следования, желательно данный параметр не трогать.
- `numbers_trains_maps_title` – текстовое отображение виды поездов дальнего следования, желательно данный параметр не трогать.
- `russian_timezones` – часовые пояса России, для корректной работы выбора часовых поясов желательно данный параметр не трогать.
